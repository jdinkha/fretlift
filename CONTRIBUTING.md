# Contributing

Thanks for helping out. A few ground rules keep the project useful and legally clean.

## Content rules

- **Don't commit audio or tabs of copyrighted songs**, including in tests,
  issues, screenshots, docs or example output. Use your own recordings,
  public-domain material, or audio generated by `scripts/make_sample.py`.
- **Don't add download features** (YouTube, Spotify, streaming rips, etc.).
  fretlift works on local files the user already has.
- New datasets or models must be listed in `DATA_AND_MODELS.md` with their license.

## Workflow

```bash
pip install -e ".[dev]"
pytest
ruff check . && ruff format --check .
```

- The core modules (`quantize`, `fretting`, `measures`, `export`) must import
  without the ML dependencies so tests and CI stay fast. Import Demucs, Basic
  Pitch and librosa inside functions.
- Add a test for every bug fix. For fingering changes, a short note sequence
  with the expected string and fret is ideal.
- When changing fingering costs, run the existing fretting tests: they encode
  what "playable" means.
